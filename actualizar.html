Convierte tu Excel de salidas en el archivo data.json que usa el buscador. El Excel no se sube a ningún lado; se procesa en tu computadora y teléfonos, correos, fechas de nacimiento y costos se descartan. Los datos se guardan cifrados con el PIN de acceso.

3. Súbelo a GitHub
  1. Abre tu repositorio en github.com y entra a el repositorio manifiesto-evento-cc-ip-foraneo.
  2. Da clic en Add file → Upload files.
  3. Arrastra el data.json que descargaste (reemplaza al anterior).
  4. Da clic en Commit changes. En 1–2 minutos el buscador muestra los datos nuevos, con el mismo link.
